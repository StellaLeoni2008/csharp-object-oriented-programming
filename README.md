## 📌 About
This repository contains the projects, exercises, and challenges developed throughout the **Learn to Program in C# with Object-Oriented Programming** learning path offered by Alura.
Throughout the courses, I explored the fundamentals of the C# language, gradually progressing to Object-Oriented Programming (OOP), code organization, collections, and data serialization.
The learning path was designed to build knowledge step by step, covering everything from basic programming logic to the development of more structured applications using object-oriented principles.

---

## 📚 Learning Path Structure

### 📁 C#.1
First steps with the C# language.
**Topics covered:**
* Variables
* Data types
* Input and output operations
* Conditional statements
* Loops
* Methods and functions
* Basic code organization

## ▶️ Running the Projects

Each folder in this repository represents a different project or stage of the learning path.

To run a specific project:

1. Navigate to the desired folder.
2. Open the project using Visual Studio Code, or another .NET-compatible IDE.
3. Run the project using:

```bash
dotnet run
```

> Requirements and dependencies may vary depending on the specific module.
