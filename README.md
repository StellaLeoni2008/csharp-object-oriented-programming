## 📌 About
This repository contains the projects, exercises, and challenges developed throughout the **Learn to Program in C# with Object-Oriented Programming** learning path offered by Alura.

Throughout the courses, I explored the fundamentals of the C# language, gradually progressing to Object-Oriented Programming (OOP), code organization, collections, and data serialization.
The learning path was designed to build knowledge step by step, covering everything from basic programming logic to the development of more structured applications using object-oriented principles.

---

## 📚 Learning Path Structure

### 📁 C#.1

The first module introduced the initial version of the **Screen Sound** application.

At this stage, the project was built using fundamental C# concepts and a menu-driven console interface, allowing users to interact with a simple music catalog while practicing programming logic and application flow.

---

### 📁 C#.2

In the second module, the Screen Sound application evolved with new features and a more organized structure.

The project became capable of handling larger amounts of information while introducing better code organization and improving the user experience through more structured menus and operations.

---

### 📁 C#.3

The third module transformed Screen Sound into an object-oriented application.

Bands, albums and songs were modeled as classes, allowing the project to represent real-world entities and relationships while making the application more scalable and maintainable.

---

### 📁 C#.4

The final module expanded the application with data persistence and external data handling.

The project introduced JSON serialization and deserialization, enabling information to be stored and loaded dynamically while maintaining an object-oriented architecture.

This stage represents the most complete version of the Screen Sound application developed throughout the learning path.

## ▶️ Running the Projects

Each folder in this repository represents a different project or stage of the learning path.

To run a specific project:

1. Navigate to the desired folder.
2. Open the project using Visual Studio Code, or another .NET-compatible IDE.
3. Run the project using:

```bash
dotnet run
```

> Requirements and dependencies may vary depending on the specific module.
